# AI on HPC Conference Website

Static website repository for **AI on HPC: Bridging Supercomputing and Artificial Intelligence**.

## Event details

- **Dates:** 23–24 February 2027
- **Venue:** Bologna Tecnopolo, Bologna, Italy
- **Organizer:** MINERVA
- **Participation:** Free of charge

Registration will open soon on the MINERVA website:
https://minerva4ai.eu/

Updates and announcements are shared on the MINERVA LinkedIn page:
https://www.linkedin.com/company/minerva-european-support-centre-for-scalable-ai-research-and-deployment/

## Website structure

- `index.html` — homepage
- `registration/` — registration information
- `program/` — preliminary program
- `directions/` — venue and travel information
- `flyer/` — conference visual
- `assets/` — stylesheets and images

## Local preview

Open `index.html` in a browser, or serve the repository with any simple static web server.
